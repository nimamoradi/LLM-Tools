### LLM-Tools
Public GitHub repository for building tools for LLMs using LangGraph and Pydantic. The current public code supports Ollama, OpenAI, and Gemini, and includes a tool-calling agent with a sandboxed Python calculator and a date-based weather tool.

**Stack:** Python, LangGraph, LangChain, Pydantic, Ollama, OpenAI, Google Gemini, SymPy, NumPy  
**Repository:** https://github.com/nimamoradi/LLM-Tools
